# Chicago rules

1. **Title 13 to 14B transition.** When a comment cites "former 13-" or "per 13-", the current code is in Title 14B. Search for the topic in 14B to find the current section.

2. **Zoning setback encroachment.** When a building element encroaches into a required setback, the governing citation is 17-13 (Zoning Board of Appeals), not 17-2. The route is other_agency because the Zoning Board must approve before the building department can proceed.

3. **Mechanical code.** Kitchen exhaust design is governed by 14M (Mechanical Code). Route to licensed_review for the mechanical engineer.

4. **Rehabilitation code classification.** Classifying work under the Building Rehabilitation Code (14R) is a professional code interpretation, not routine paperwork. Route to licensed_review.

5. **Density calculations.** Lot area per unit and similar density calculations in residential districts are the architect's professional judgment. Route to licensed_review; do not supply or compute the numbers.
