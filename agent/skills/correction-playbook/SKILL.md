# Correction playbook

Go through every item for each comment.

1. **Discipline.** What is the comment really about? Ignore the letter's heading; look at the substance.
2. **Citation.** Which section governs it? Look it up with search_code and get_section.
3. **Route.** Who has to act next?
   - **licensed_review**: Design decision, code interpretation, or professional judgment. The architect or engineer chooses values, methods, or approaches.
   - **agent_draft**: Routine paperwork with no design content. You can prepare it for sign-off.
   - **client_input**: Needs a fact or document from the owner, contractor, or consultant.
   - **other_agency**: Needs action from a body other than the building department.
   - **no_action**: Nothing to do.
4. **Sheets.** Which sheets from the index must be revised? Include only sheets that will actually change.
5. **Draft.** Write the response for the licensed professional to sign.
   - For **licensed_review** items: describe what needs to be shown or added, without stating compliance, supplying numbers, or dictating the solution.
   - For **agent_draft** items: state the correction to be made.
   - For **client_input** items: state what document or information is needed.
   - For **other_agency** items: state what approval is needed and from whom.
   - For **no_action** items: leave draft empty.
6. **Certified Plan Corrections.** If the item requires a sheet revision (licensed_review or agent_draft with sheets), the draft must indicate the revision will be bubbled, dated, and initialed by the licensed professional.
