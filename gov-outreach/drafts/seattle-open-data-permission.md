## Before you send

- Open the dataset page and check that the last update date hasn't changed.
- The permission ask promises to remove names and not to republish without asking. Send it only if you'll keep that.
- Requests must be for identifiable records (RCW 42.56.080(1)). Name the record type and the date range.
- An agency may deny a request it reasonably believes a program or script generated, if it is one of several from the requester within 24 hours and they cause excessive interference (RCW 42.56.080(3)). A person sends these, one per agency.

## Ask a lawyer

- Do the public domain terms on the dataset cover the linked letter documents? Letters can name people.
- Ask a lawyer whether comment records that name people could be treated as a list of individuals. We state the purpose anyway, because hiding it is not worth the risk and the agency may ask.
