## The text

```text
Subject: Question about bulk access to building review comments on Application Status

Hello,

My name is [Your full name]. [Entity name] builds software that helps architects and permit expediters respond to plan review correction comments, and intends to charge for it. The records would be used to test and improve that software on real comments.

I'm writing about public building review comments on the Planning Application Status pages. To test the software on real comments rather than ones we wrote, we would like to use them. I'm asking you rather than assuming.

So far we have read two comment pages and a few related pages, one at a time, to see what the site holds. We haven't crawled it, and I'm asking before doing anything more.

**Three questions:**

1. Is there a bulk export or data extract of building review comments?
2. If not, would the County accept slow automated retrieval from those pages, at a rate and hours you set? We would not do this without a yes.
3. What conditions apply to using the comments, such as attribution or no redistribution?

We would remove personal names and contact details before testing, and we wouldn't republish the comments without asking.

If the answer to these is no, I'd make a small public records request instead. A short answer is plenty, and I'm happy to talk by phone.

Thank you.

[Your full name]
[Entity name, if any]
[Mailing address]
[Email]
[Phone]
```

## Before you send

- Using the portal may mean accepting its terms. That's your decision, so read them first.
- Use the County's designated method. Under AB 1821 as read, other routes may not start the deadline from January 1, 2027.
- Requests received in 2026 use 10 calendar days. From 2027, 10 business days as read. Check the chaptered text.
- The permission ask promises to remove names and not to republish without asking. Send it only if you'll keep that.
- Under AB 1821 as read, a request counts as properly made only through a method the agency designates. Use the listed method so the deadline applies. Unconfirmed against the chaptered text.

## Ask a lawyer

- Read the chaptered text of AB 1821 for what it changes, and whether commercial use affects fees.
- Read the chaptered text of AB 1821 (Chapter 899, Statutes of 2026) on fees, submission methods and its start date. Ask whether it changes how a commercial request is treated.
